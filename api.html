Developer Documentation

GrowthGod API ● Live · v1

Full Instagram operations over REST: publish feed posts and stories, like/comment/save, follow and DM, edit profiles, search venues by location, pull hashtag and explore feeds — every call executes on your own connected accounts. Keys are scoped read / engage / dm.

Quickstart

1 · Connect an Instagram account in the dashboard.
2 · Create an API key (Settings → API keys, or POST /api/api-keys). The plaintext key igk_live_… is shown once — store it.
3 · Call the API with that key.

List your connected accounts 
curl https://api.growthgod.com/api/v1/me \
  -H "Authorization: Bearer igk_live_YOUR_KEY"
Search Instagram venues near Lagos 
curl "https://api.growthgod.com/api/locations/search?q=Lagos&lat=6.5244&lng=3.3792&account_id=ACCOUNT_UUID" \
  -H "Authorization: Bearer igk_live_YOUR_KEY"

Post a story 
curl -X POST https://api.growthgod.com/api/v1/accounts/ACCOUNT_UUID/publish/story \
  -H "Authorization: Bearer igk_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "media_url": "https://cdn.example.com/clip.mp4", "media_type": "video" }'
Authentication

Per-User API Keys

Every key belongs to one dashboard user and can only operate Instagram accounts that user has connected. Requests run on those accounts' sessions — never shared infrastructure. Send the key either way: 

Authorization: Bearer igk_live_…
# or
x-api-key: igk_live_…

Scopes

read — GET data · engage — likes/comments/follows/publishing · dm — direct messages. Request scopes at key creation.

Hardening options

Keys support expiry, IP allowlists, and mandatory HMAC request signatures for high-trust integrations.

Ownership

Every account_id is verified against your user. Another user's account id returns 403.

Endpoints

Base URL: https://api.growthgod.com · All bodies are JSON.

POST/api/v1/accounts/{accountId}/publish/photoengage

{ image_url, caption?, location_id? } → publishes a single image. Returns media_id + permalink.

POST/api/v1/accounts/{accountId}/publish/videoengage

{ video_url, caption?, cover_url?, is_reel? } → feed video or Reel.

POST/api/v1/accounts/{accountId}/publish/carouselengage

{ media_urls[2–10] (jpg/png/mp4 auto-detected), caption? } → album post.

POST/api/v1/accounts/{accountId}/publish/storyengage

{ media_url, media_type: "photo"|"video" } → story. Videos need MP4.

POST/api/v1/accounts/{accountId}/stories/{storyMediaId}/{action}engage

view {target_user_id} · like / emoji {owner_user_id, emoji?} · poll {poll_id, vote:0|1} · slider {slider_id, value:0–1} · quiz {quiz_id, answer_index:int}

POST/api/v1/accounts/{accountId}/media/{mediaId}/like | comment | save | unsaveengage

comment takes { text }. Returns action status.

GET/api/v1/accounts/{accountId}/media/{mediaId}/likers | commentsread

Who liked it; comment threads with authors.

POST/api/v1/accounts/{accountId}/users/{targetUserId}/{action}engage

follow · unfollow · block · unblock · mute {posts?,stories?} · unmute

GET/api/v1/accounts/{accountId}/users/{targetUserId}/{what}read

info · feed · stories · highlights · followers · following · chaining. Accepts numeric pk or handle for info/feed.

GET/api/v1/accounts/{accountId}/search/users?q=read

Instagram user search by handle/name fragment.

GET/api/v1/accounts/{accountId}/feed/hashtag?tag= | feed/exploreread

Hashtag media grids and the discover tab feed.

GET/api/v1/accounts/{accountId}/music/trending | music/search?q= | music/moodsread

Trending audio, track search, mood catalogs (Reels-ready).

GET/api/v1/accounts/{accountId}/locations/search?q=&lat=&lng=read

Live venue search (Facebook Places IDs). Coordinates sharpen results; country/city names work when coords are nearby.

GET/api/v1/accounts/{accountId}/locations/{locationId}/feed?cursor=read

Recent posts at a venue + poster list with has_more/next_cursor pagination. Also available without prefix at /api/locations/*.

POST/api/v1/accounts/{accountId}/profileengage

{ username?, display_name?, bio?, external_url?, email?, phone? } — omitted fields unchanged. Also /profile/photo ({image_url} or {remove:true}) and /profile/privacy ({mode:"private"|"public"}).

GET/api/v1/me · /api/v1/accounts/{accountId}/meread

Your user + connected account list · the IG identity behind one account.

POST/api/v1/dm/{accountId}/senddm

{ target_user_id, text }. Also /unsend {thread_id,item_id}, GET /inbox, GET /thread/:threadId.

Errors

Error Format

Stable machine-readable codes — branch on error, show message to humans.

StatuserrorMeaning / fix
400invalid_request textMissing/invalid parameter — see message.
401No authorization tokenMissing/expired/revoked key.
403insufficient_scopeKey lacks required scope (read/engage/dm).
403Account not found, not owned by you…Wrong or foreign account_id.
423ACCOUNT_KILL_SWITCH_ACTIVESafety lockout (checkpoint/action-block). Account needs attention in dashboard.
503instagram_session_expiredReconnect this account to refresh its session.
503instagram_checkpointClear IG's challenge for this account, then retry.
500internal_errorRetry with backoff; persistent errors → support.
Account-safety model: risky signals trip a per-account circuit breaker that pauses all actions until cleared — protecting your account over your integration's uptime.
