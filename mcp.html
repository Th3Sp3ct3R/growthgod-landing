Developer Documentation

GrowthGod MCP Server

The Model Context Protocol server exposes GrowthGod's full social-intelligence surface as native tools for your AI agent. Ask Claude or Cursor to benchmark a competitor, sweep brand mentions, or pull trend data — no glue code required.

One-line install (Claude Code) 
claude mcp add growthgod \
  --env GROWTHGOD_API_KEY=gg_live_YOUR_API_KEY \
  -- npx -y @growthgod/mcp serve
Overview

Your agent, wired into the data

The MCP server wraps the GrowthGod REST API in typed tools and streams results back to the model. Runs locally via stdio — your API key never leaves the machine except in requests to api.growthgod.com.

Typed tools

Seven schema-validated tools with descriptions tuned so agents pick them correctly without few-shot examples.

Local transport

stdio-based server launched on demand by your MCP client. No daemon, no ports.

Same quotas

Tool calls consume your plan's REST quota identically. Rate-limit errors surface as readable tool errors.

Setup

Installation & Configuration

Requirements: Node.js 20+, a GrowthGod API key (gg_live_… or gg_test_…).

Claude Desktop · claude_desktop_config.json 
{
  "mcpServers": {
    "growthgod": {
      "command": "npx",
      "args": ["-y", "@growthgod/mcp", "serve"],
      "env": {
        "GROWTHGOD_API_KEY": "gg_live_YOUR_API_KEY"
      }
    }
  }
}
Generic MCP client config

Any client supporting the stdio transport uses the same shape — command npx, args -y @growthgod/mcp serve, with the key in env.

Sandbox first: set GROWTHGOD_API_KEY to a gg_test_… key while evaluating. Sandbox calls return fixture data and never touch live quota.
Reference

Tools

All tools are read-only. Exports return job handles that the agent can poll.

gg_list_platforms

Returns supported platforms and per-platform coverage notes. Call this first when platform slugs are unknown.

InputTypeDescription
No inputs.
gg_get_account_profile

Public profile snapshot for one account: bio, category, verification state, follower counts, posting cadence.

InputTypeDescription
platformstringPlatform slug from gg_list_platforms. Required.
handlestringAccount handle without @. Required.
gg_get_account_stats

Time-series followers, engagement rate, views, and post volume — the benchmarking workhorse.

InputTypeDescription
platformstringPlatform slug. Required.
handlestringAccount handle. Required.
periodenum7d, 30d, 90d, 1y. Default 30d.
granularityenumdaily or weekly. Auto-chosen if omitted.
gg_search_mentions

Keyword/boolean search over public mentions across platforms with date, language, and sort controls.

InputTypeDescription
querystringKeyword, quoted phrase, or boolean expression. Required.
platformsarrayOptional subset of platform slugs.
from / todateInclusive window, ISO 8601. Max span 180 days.
sortenumrelevance, recent, engagement. Default relevance.
limitint10–100. Default 25.
gg_analyze_sentiment

Sentiment scores for raw texts or mention IDs, with aggregate distribution. Use after gg_search_mentions to gauge brand mood.

InputTypeDescription
mention_idsarrayUp to 500 IDs. Provide this XOR texts. Required.
textsarrayRaw strings (≤2,000 chars each). Provide this XOR mention_ids. Required.
gg_get_trends

Rising topics, hashtags, and sounds ranked by acceleration for a category/region — the early-signal feed.

InputTypeDescription
categorystringe.g. fashion, fitness, beauty, food-beverage. Default all.
regionstringISO country code. Default global.
periodenum24h, 7d (default), 30d.
gg_export_dataset

Queue an async CSV/JSONL/Parquet export of mentions or account stats. Returns a job ID; poll it in follow-up turns until ready.

InputTypeDescription
sourceenummentions or account_stats. Required.
filterobjectMentions-search-shaped filter, or {platform, handle, period} for stats. Required.
formatenumcsv, jsonl, parquet. Default csv.
Example result 
{
  "job_id": "exp_01J9ZK...",
  "status": "queued",
  "note": "Poll gg_export_dataset status via job_id. Typical completion: 1–4 min."
}
In Practice

What this looks like in chat

You
Compare our handle vs our biggest competitor on TikTok — followers and engagement over the last 90 days.
Agent
Pulling both profiles… gg_get_account_stats × 2 (period 90d, weekly). Your engagement rate is up 18% while theirs flattened after June 14 — want me to export the underlying series as CSV?
You
Sweep mentions of "cold brew" from July and tell me how sentiment shifted.
Agent
gg_search_mentions (July window, engagement sort) → 412 hits → gg_analyze_sentiment on all IDs. Positive share rose 61% → 74%; two spike days align with creator collabs.
You
What's accelerating in fitness right now?
Agent
gg_get_trends (fitness, global, 7d): "kettlebell flows" +340% velocity, "zone 2 walking" plateauing. Three rising sounds attached.
